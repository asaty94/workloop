# スキルから作業対象リポジトリの .github への言及をなくす

- Issue: なし
- PR: #7
- workloop: 0.2.2

## 起きたこと

- 担当者の提案で、プラグインが干渉できない作業対象リポジトリの `.github/` について、スキルに書かないことにした。
- README の最初の案では「AI は `.github/` のテンプレートを使いません」と書いていた。AI の振る舞いを言い切りすぎているので、「スキルは参照しません」に直した。

- マージ（手順 12）で、#5 をブランチ削除付きでマージした。すると、#5 のブランチを向き先にしていた #6 は、main に切り替わらずに閉じられた。PR には「GitHub が自動で切り替える」と、確かめないまま書いていた。#5 のブランチを戻して #6 を開き直し、向き先を main にした。版の行が衝突したので main を #6 に取り込み、#7 にも #6 を取り込んだ。どちらも、取り込んだあとの差分が元と同じことを確かめた。
- 衝突を解消するために積み直して強制 push しようとしたが、Claude Code の自動判定で止められた。担当者に相談し、強制 push を使わずに main を取り込む方法に変えた。

## workloop への気づき

- 8 章に、別の PR のブランチを向き先にした PR（積み重ねた PR）のマージ手順がない。向き先のブランチを削除すると、後ろの PR は閉じられる。そのため、ブランチを削除する前に、後ろの PR の向き先を main に変える必要がある。

- 5 章の `.github/` の 1 文は、スキルの外にある形式を AI に埋めさせる決まりで、スキルのひな形と基準が 2 つになっていた。
