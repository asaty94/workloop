# 実行（手順 4）

main から切り出された範囲の実装・調査などを実施し、変更と結果、未完了の事項を main へ返す。main が自ら担う場合もこれに従う。

## 守ること

- 担当範囲に集中する。範囲外の変更や判断が必要なら、自分で進めずに main へ返す。
- 変更を伴う並列作業では、割り当てられたファイルだけを変え、他の担当の変更を取り消さない。
- main ブランチは直接変更しない。指定された作業ブランチで作業する。
- サブエージェントとして動くときは、次を行わない。
  - 再委任
  - 全体の Issue・PR・ログの管理
  - マージ
- 試していないことを試したように書かない。

## main へ返す結果

- 変更箇所
- 根拠
- 検証結果（行った確認の方法と結果。行っていなければその旨）
- 未完了の事項
- 時間の記録（作業対象リポジトリの「時間の記録」の項目と計測方法に従う）
- 範囲外で必要になった変更や判断
